# templates

Master templates: specification, proposal, quotation, release notes, reports, and the billing set.

All document and report templates include the Knotica letterhead. The source asset is maintained at `KNOTICA ERP SYSTEM/CONFIGS/assets/knotica-letterhead.png` and copied into each published module's `assets/` directory. Preserve the letterhead when creating a derivative template, but do not change required fields, identifiers, approval sections, formulas, or workflow metadata.

| Group | Templates |
|---|---|
| Delivery | `specification-design.md`, `release-notes.md`, `handover-report.md`, `incident-report.md` |
| Sales | `proposal.md`, `quotation.md` |
| Billing | `invoice.md`, `payment-receipt.md`, `credit-note.md`, `statement-of-account.md`, `payment-reminder.md`, `billing-schedule.md` |
| Examples | `examples/` |
