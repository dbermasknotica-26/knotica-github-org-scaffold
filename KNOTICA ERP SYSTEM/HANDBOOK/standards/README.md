# standards

Naming, labels, branching, documentation style, client code register.

## Document ID patterns

| Document | Pattern | Example | Where |
|---|---|---|---|
| Specification | `SPEC-<CODE>-###` | `SPEC-NWB-001` | `cl-*/01-specs` |
| Proposal | `PROP-YYYY-###` | `PROP-2026-014` | `sales` |
| Quotation | `QUO-YYYY-###` | `QUO-2026-031` | `sales` |
| Invoice | `INV-YYYY-###` | `INV-2026-001` | `billing` |
| Payment acknowledgement | `RCT-YYYY-###` | `RCT-2026-001` | `billing` |
| Credit note | `CN-YYYY-###` | `CN-2026-001` | `billing` |
| Statement | `STMT-<CODE>-YYYY-MM` | `STMT-NWB-2026-10` | `billing` |
| Incident | `INC-YYYY-###` | `INC-2026-007` | `internal-ops` |
