# handbook

_Knotica Solutions Inc_

Company processes, policies, SOPs and template library.

## Structure

| Folder | Purpose |
|---|---|
| `processes/` | Workflow maps (Mermaid) and SOPs: sales, delivery, support, release. |
| `policies/` | Security, data handling, code of conduct, leave, travel. |
| `onboarding/` | New staff and new client onboarding checklists. |
| `templates/` | Master templates: specification, proposal, quotation, release notes, reports, and the billing set (invoice, payment acknowledgement, credit note, statement, reminders, billing schedule). |
| `standards/` | Naming, labels, branching, documentation style, client code register. |
| `training/` | Guides, including GitHub for non-developers. |
