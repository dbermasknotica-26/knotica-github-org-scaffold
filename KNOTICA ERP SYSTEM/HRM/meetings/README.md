# HRM Meetings

Meeting records cover weekly, monthly, all-hands, and other approved internal
meetings. Use [`meeting-minutes.md`](meeting-minutes.md) for every new record.

## Required meeting details

Each record must include:

- Meeting title, date and time, meeting platform or location
- Present and not-present attendees, facilitator, and note taker
- Action items using the exact columns: Category, Action Item, Owner, Priority,
  Due, Status, and Remarks
- Priority and status meanings are defined in the Legend section of the
    meeting template.
- Confirm action owners, due dates, and status before publication or notification

The standard template follows the supplied partner-meeting format and includes
the Knotica letterhead. Do not remove the letterhead, required fields,
workflow metadata, or approval section when creating a meeting record.

## HRM Agent usage

Use the HRM Agent to create a draft from this template:

> **HRM Agent:** Create a draft meeting record for `<title>` on `<date>`.
> Include the attendees, objectives, agenda, decisions, and action items.
> Output: draft only. Approval: required.

The agent may extract owners, due dates, risks, and follow-up actions, but it
must not publish sensitive HRM information, change leave or incident status,
or send notifications without human approval.
