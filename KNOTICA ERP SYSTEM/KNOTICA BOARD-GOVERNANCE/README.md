# board-governance

Board resolutions, approvals, minutes (restricted).

| Folder | Purpose |
|---|---|
| `resolutions/` | BRD-YYYY-###-title.md. Approved = merged. |
| `approvals/` | Approval requests raised as pull requests. |
| `minutes/` | Board meeting minutes. |
| `decks/` | Board presentations (PDF). |
| `financial/` | Budget and approval summaries. No raw payroll or bank data. |
