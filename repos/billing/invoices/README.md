# invoices

Issued invoices, one folder per year: `invoices/2026/INV-2026-001-nwb-deposit.md` (+ the PDF export that went to the client).

- Prepare from `handbook/templates/invoice.md`. Take the next ID from the register.
- Never edit an issued invoice. Issue a credit note (`credit-notes/`) and, if needed, a new invoice.
- A cancelled number is voided in the register; the file stays (marked VOID) so there is no gap in the sequence.
